# EcoLoop Recycling Platform 

EcoLoop is a web-based recycling platform prototype designed for University of Venda students.

## Problem Identified
Students may have limited information about recycling, where recyclable waste should be taken, and how waste problems can be reported.

## Solution
EcoLoop provides:
- Waste reporting
- Recycling categories
- Campus collection points
- Recycling activity dashboard
- Student login and registration interfaces

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a browser.
3. For development, use VS Code with the Live Server extension.
